# Magical Attacks

Magical attacks use the same structural logic as physical attacks.
They differ mainly in which defensive pool they target.

Typical mapping:
- direct magical projectile -> **Stance**
- fear / illusion / domination -> **Resolve**
- body-crushing / draining / transformation -> **Stamina**

Magical attacks:
- follow normal VT timing
- fail if they do not overcome Guard
- do not automatically target Resolve just because they are magical
