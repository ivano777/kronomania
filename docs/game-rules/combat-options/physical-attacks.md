# Physical Attacks

Physical attacks are direct hostile actions expressed through the shared combat engine.

Typical examples:
- melee strikes
- arrows
- thrown weapons
- direct bodily blows

Default defense:
- **Stance**

A physical attack:
- follows VT timing
- pressures the relevant Guard
- causes Wounds if it breaks through

Repeated physical attacks in the same turn usually continue to consume the same Stance pool instead of triggering repeated re-rolls.
