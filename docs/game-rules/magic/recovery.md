# Recovery

## Long Rest
A Long Rest:
- removes Burnout
- resets Fervor to base Size

## Recovery Scene
A Recovery Scene:
- removes Burnout
- does **not** reduce current Fervor Size

## Ingenuity Reduction and Recovery
If a temporary effect lowers Ingenuity and Fervor is clamped to the new cap:
- This clamp-down does **not** count as recovery.
- It does **not** remove Burnout.
- Only a valid recovery effect (Long Rest, Recovery Scene, or a node ability) removes Burnout.

See [Fervor — Ingenuity Reduction Interaction](./fervor.md#ingenuity-reduction-interaction) and [Burnout](./burnout.md) for the full rules.

## Safe Venting
Safe Venting is **not** a baseline rule.

If Fervor can be reduced directly, that should usually come from:
- a node
- a rare ability
- a special scripted effect

Example node pattern:
- when Fervor would cause Burnout,
- once per day,
- reduce Fervor by up to a number of steps equal to Tier
