# Core Rules Overview

The Core Rules define the shared gameplay engine.

They describe:
- stats and dice;
- pool building;
- Keep;
- modifiers;
- equipment interaction;
- combat timing;
- defense and Guard.

## Core Engine Summary
Most actions follow:

**Build Pool -> Roll -> Keep -> Flat -> Outcome**

This structure applies to:
- physical attacks
- magical attacks
- cantrips
- true spells
- defense rolls
- contested utility actions
