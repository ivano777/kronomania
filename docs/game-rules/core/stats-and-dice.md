# Stats and Dice

## Core Stats
The game uses three core stats:
- **Dominion**
- **Negation**
- **Ingenuity**

## Defensive Expressions
- Dominion -> **Stamina**
- Negation -> **Stance**
- Ingenuity -> **Resolve**

## Stable Dice Scale
Normal stable progression:
- d4
- d6
- d8
- d10

Exceptional / temporary only:
- d2
- d12

## Default Stat Assignments
Unless a rule, spell, item, or feature explicitly overrides it:
- Default **offensive** stat: **Dominion**
- Default **defensive** stat: **Negation**
- Default **mental / cognitive / control** stat: **Ingenuity**

These defaults apply to action examples, combat wording, and magic wording unless a specific rule names a different stat.

## Stable Size vs Temporary Size
A stat may have:
- a **stable Size**
- a **temporary effective Size**

Stable Size matters for rules such as:
- cantrip knowledge
- progression requirements

Current modified Size matters for:
- Fervor containment (the Fervor cap is based on **current modified Ingenuity**, not stable Ingenuity)
