# Combat

Combat is treated as a pressure exchange built on the same shared engine as the rest of the game.

## Combat as Pressure
Hostile actions generate pressure.
Defense rolls generate Guard.
Guard absorbs pressure until it breaks.

## Shared Resolution
Combat actions still use:

**Build Pool -> Roll -> Keep -> Flat -> Outcome**

## Main Combat Questions
Each hostile action usually answers three questions:
1. when does it resolve?
2. which defense pool does it pressure?
3. does it overcome Guard?

## Mixed Threats
Mixed threat types are dangerous because they may force:
- Stance,
- Resolve,
- and Stamina

within the same turn.
