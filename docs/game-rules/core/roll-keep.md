# Roll / Keep

## Resolution Flow
**Build Pool -> Roll -> Keep -> Flat -> Outcome**

## Pool
Base pool size is determined by **Tier**.
- Tier 1 -> 1 die
- Tier 2 -> 2 dice
- Tier 3 -> 3 dice
- Tier 4 -> 4 dice

The die Size comes from the relevant stat or action rule.

## Keep
Baseline training scale:
- Grade 0 -> keep 1
- Grade 1 -> keep 2
- Grade 2 -> keep 3

Unless a rule says otherwise, keep the best valid dice.

## Flat
Flat modifiers are applied after Keep.

## Forced Inclusion
Some systems force a die to be kept.
The main example is the **Fervor Die**.

## Failure and Success
- attacks, cantrips, and spells fail if they do not overcome Guard;
- a low VT result usually makes the action Slow rather than invalid.
