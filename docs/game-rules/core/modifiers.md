# Modifiers

## Modifier Categories
- **Status** -> changes **Size**
- **Situation** -> changes **Pool**
- **Flat** -> changes the final total after Keep

## Status
Status changes the effective Size of the relevant stat.
It does not rewrite **stable Size**.

## Situation

### Advantage
Adds +1 die to the pool.

### Disadvantage
Removes -1 die from the pool.

### Cancellation
Advantage and Disadvantage cancel each other 1-for-1.
Any remaining net Advantage or Disadvantage applies normally.
Remaining Disadvantage may stack (multiple sources each remove 1 die).

## Desperation
If net Disadvantage would reduce the **normal pool** to 0 dice:
- enter **Desperation**: roll 2 dice, keep the worst.

Desperation applies to the **normal pool only**.
Real Fervor dice are still rolled as additive dice afterward, unaffected by Desperation.
Substitution dice are part of the normal pool and are affected by Desperation like any other normal pool dice.

## Cumulative Defensive Disadvantage
If multiple **different** defense pools must be rolled in the same turn,
each additional defensive roll takes cumulative disadvantage.
