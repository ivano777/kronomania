# Tiers

Tier is the main progression term for base pool size.

Baseline mapping:
- Tier 1 -> 1 die
- Tier 2 -> 2 dice
- Tier 3 -> 3 dice
- Tier 4 -> 4 dice

Tier is distinct from:
- stat Size
- Keep
- Flat

Tier advancement requires category breadth in the Constellation.

| Tier | Base Pool | Breadth Requirement |
| --- | --- | --- |
| Tier 1 | 1 die | starting state |
| Tier 2 | 2 dice | 1 Core, 1 Training, 1 Ability, 1 Flavor |
| Tier 3 | 3 dice | 2 Core, 2 Training, 2 Ability, 2 Flavor |
| Tier 4 | 4 dice | 3 Core, 3 Training, 3 Ability, 3 Flavor |
